# KineticRhythm（キネティック・リズム）

変拍子（5/8・7/8 など）の「いびつな重心・タメ・周期性」を、動きと音で体感するための教育用Webアプリです。

## ことば
- 拍＝指揮で振る単位＝まとまり（パン＝刻み2つの短い拍、トマト＝刻み3つの長い拍）。5/8は2拍子、7/8は3拍子
- 刻み＝8分音符1つ分
- 強さは3段階：小節の頭 ＞ 拍の頭 ＞ 刻み（音も見た目も3段階。小節の頭は、どのモードでも緑の光とランプ）

## 使い方
`index.html` をブラウザ（Chrome / Safari など）で開くだけで動きます。

- 画面の配置：上＝モード選び、まん中＝絵（上に拍子、下に1行の説明。「？」でくわしい説明）、いちばん下＝いつも使う操作
- 下のバー：再生／停止・テンポ（−＋）・今のリズム（押すと選べる）・設定・全画面
- モードは3つのグループ：きほん（多角形・ボール・円軌道・指揮・階段）／ふしぎ（ポリリズム・紋章・歯車・しずく・振り子・花）／たのしい（電車・花火・踊る人・ドミノ・ジャグリング・ゼリー・ノーツ・カエル・からくり・ブロック積み）。上の今のモード名を押すと一覧が出る（◀▶・←→キーでも切り替え）
- 設定（右、スマホでは下から出る引き出し）：リズムを選ぶ・授業で使う・練習する・リズムを作る・ポリリズム・表示と音・ズレ補正
- 授業で使う：再生前のカウント（そのリズムで1小節）、止めかた（小節の終わりで／すぐ）、この設定を配る（URLとQRコード）
- 全画面：操作をかくし、マウスを動かすと出る。再生中は画面が消えないようにする
- 楽譜バー：画面の下に1段のリズム譜（拍子記号・拍ごとに連桁でつないだ8分音符・アクセント・小節線・くり返し記号）。今鳴っている音符が光る。拍子記号をタップすると意味の説明が出る（設定でON/OFF）
- キーボード：スペース＝再生／停止、F＝全画面、←→＝モード、↑↓＝テンポ±5、[ ]＝リズム、J・Enter＝タップ判定でたたく、Esc＝閉じる

## プリセット
- ふつうの拍子：2/4・3/4・4/4・6/8
- 変拍子：5/8 [2+3] / [3+2]、7/8 [2+2+3] / [3+2+2]、8/8 [3+3+2]（トレスティーヨ）
- 交互にくり返す：5/8 [2+3]→[3+2]、7/8 [2+2+3]→[3+2+2]、6/8→3/4（ヘミオラ）

## 各モード
- A 転がる図形：3/4は三角形、4/4は四角形（1辺＝1拍）。5/8は五角形、6/8は六角形（1辺＝8分音符、拍の頭の角がとがっている）。角が床につく瞬間に音が鳴る。白い線は重心の軌跡
- B ボール：奥の大きいボール＝グループ（2か3）、手前の小さいボール＝8分音符
- C 円軌道：1周＝1小節（交互パターンでは2小節）
- E 階段：顔つきのボールが8分音符ごとに跳ね、拍の頭で次の段へ。1小節目はのぼり、2小節目はくだり
- D 指揮：打点は横一列（打点の面）に並び、拍と拍は小さな山でつながる。1拍目は高いところからまっすぐ振り下ろし、最後の拍のあと高く上がって戻る。2つ振り（下・上）、3つ振り（下・外・上）、4つ振り（下・内・外・上）、6つ振り（下・内・内・外・外・上）。5/8・7/8 はグループの数で振り方を選び、長い拍（3）は同じ形のままゆっくり動く。「左右反転」で生徒側から見た向きに切り替え可

- G 電車：パン＝短い車両、トマト＝長い車両。レールの継ぎ目を車両の継ぎ目が通ると「ガタン」（拍の頭）、車両の中の車輪が通ると「コトン」（刻み）。小節の頭の車両は黄緑色
- H 拍子の紋章：円のまわりを光が走り、8分音符ごとに点を打って線でつなぐ。拍の頭は外側に大きく、刻みは内側（トマトはより深く）。1周ごとに少し回して重なり、万華鏡のように育つ。「模様をリセット」で描き直し
- I 花火：拍の頭で大きな花火（ドン）、刻みで小さな火花（パチッ）。トマトの花火は大きく長く光る。小節の頭はピンクの二重の花火。開く場所は毎小節同じ
- J 歯車：刻み→拍→小節の3つの歯車。刻みの歯車は1刻みで1マス進み、1回転でちょうど1小節。歯は拍の頭のマスにだけあり、歯のあいだはパン＝2マス、トマト＝3マス。拍の歯車はふつうの歯車で、歯がかみ合う拍の頭のときだけ回る。拍の歯車の前の小さな歯車には小節の頭の拍にだけ歯があり、緑の「小節の歯車」は小節の頭のときだけ歯1つぶん回る（歯1つ＝1小節、まん中に何小節目か）
- K 踊る人：シルエットの人がバレエのように踊る。刻みではつま先で小刻みに1歩ずつ進み、強拍（拍の頭）でひざを深く曲げてぐっと踏み込み、腕を大きくひらく。強拍は色つきの大きな足あと、刻みは小さな点の足あとが残り、並びは小節ごとに同じになる（5/8・7/8はバルカン半島の民族舞踊でも使われる）
- ドミノ：8分音符1つ＝ドミノ1枚。1拍かけて倒れ、次のドミノに当たった瞬間に音。拍の頭は背の高いドミノ（トマトの頭がいちばん高い）。小節の頭に旗
- ジャグリング：まとまり1つ＝1回の投げ。パンは低く、トマトは高く（空中の時間が長いほど高い）。左右の手で交互に投げ、手に落ちる瞬間に音。軌道の上の点は8分音符ごとの位置
- しずく：8分音符の数だけ、しずくの落ちる場所が並ぶ。しずくは落ちてきて拍の瞬間に水面に着き、波紋が広がる。拍の頭は大きなしずく（トマトの波紋がいちばん大きく長い）。毎小節、同じ場所に同じしずくが落ちる
- ゼリー：まとまり1つ＝ゼリー1つ（パンは小さく、トマトは大きい）。サクランボがゼリーからゼリーへ跳び、乗った瞬間にゼリーがぷるんとゆれる。トマトのゼリーは大きく長くゆれる
- 振り子：左にパンの振り子（短いひも）、右にトマトの振り子（長いひも）、まん中に鐘。拍の頭で鐘に当たり、その勢いで次の振り子が飛び出す（ニュートンのゆりかご）。ひもの長さは2.25倍で、行って戻る時間は1.5倍（2拍と3拍）。本物の振り子と同じしくみ
- ノーツ（音ゲー風）：右から流れてくる大きな丸（拍の頭）が線に重なった瞬間にタップ（J・Enterキーでも）。うしろの帯の長さ＝まとまりの長さ。このモードではタップ判定がOFFでも叩ける。連続ぴったりの数を表示
- 花：まとまり1つ＝花1つ。拍の頭でつぼみがポンと開き、8分音符ごとに花びらが2枚ずつふえる（パン＝4枚、トマト＝6枚）。1小節ぶんが1列の花だんになり、小節ごとに列が奥へ下がる
- カエル：ハスの葉の間かくがパン＝2マス、トマト＝3マス。カエルは拍の頭で葉に着地して「ケロッ」。トマトは遠く高く跳ぶ。小節の頭の葉にはハスの花
- からくり：玉が仕掛けを1拍に1つずつ鳴らして進む。パン＝ばね台→ドミノ、トマト＝卓上ベル→鉄琴の板2枚。小節の最後でゴールに入って旗が立ち、上の管を通って最初の仕掛けにもどる。交互パターンの2小節目は色と仕掛け（太鼓・おりん）が変わる。「リズムを作る」のカードの順番がそのまま仕掛けの並びになる
- ブロック積み（ゲーム）：上から「2」「3」のブロックが落ち、着地の瞬間（拍の頭）にタップ。ぴったり／早い／遅いを表示し、1小節そろうと列が光って消える。スコアと連続ぴったりの数を表示。「見るだけ」で自動にもできる。判定にズレ補正を使う
- くらべる：組み合わせに「パン（3/4）とトマト（6/8）」「6/8 と 2/4 の3連符」もある。上下2段に2つのリズムを同じ時間の目もりで並べる（5/8 2+3と3+2／6/8と3/4／4/4と8/8(3+3+2)／7/8 2+2+3と3+2+2／自分で作ったリズムどうし）。表示はドミノ・電車・円軌道から選べる。縦の点線＝刻み、▼▲＝それぞれの拍の頭、◆＝両方そろう所。上下で音色がちがい、片方だけ鳴らすこともできる。6/8と3/4はヘミオラ（2対3）
- 当てる（聴き取りクイズ）：映像をかくして音だけ2小節。「2+3？3+2？」「何拍子？」などを選ぶ。答えると映像と楽譜つきでもう一度鳴る。やさしい／ふつう／むずかしい／連符（何連符？）／楽譜を見て答える の5つ、問題の前に刻み4つのカウント、小節の頭はベルの音。答えのあとに1行の解説。まちがえたら「自分の答えとくらべる」（上下2段）。10問で結果、まちがえた問題はもう一度聞ける
- 連符（🍡）：1拍（♩＝刻み2つぶん）を2〜7つに等しく分ける。円の針が1周する間が1拍、帯は1小節ぶん、楽譜バーには3連符・5連符・7連符の数字つきで出る
  - 数えることば：2＝パン、3＝トマト、4＝からあげ、5＝さつまいも、6＝とうもろこし、7＝いちごだいふく
  - 練習の順番：2→3→4→5→6→7／2→3→2→5→2→7（ふつうと交互）／3→5→7／1つだけ。1つを続ける長さ（1・2・4小節）と1小節の拍（2・3・4拍）を選べる。次に変わるときは予告が出る
  - 「ふつうの刻みとくらべる」ON：8分音符（パン）を太鼓の音で同時に鳴らし、下の段に並べてずれを見せる
  - タップ判定ONで、連符を自分で叩いて判定できる

## 練習機能
- タップ判定：画面タップ、または J・Enter キーで拍を叩くと「ぴったり／早い／遅い」を絵の下の行に表示。「拍の頭だけ」も選べる。ズレ補正の値も判定に使う
- 補助を少しずつ消す：① 全部あり → ② 映像なし → ③ 刻みなし → ④ 音なし → 音が戻る、をくり返す。1段階の長さと音なしの長さを選べる
- テンポ自動アップ：はじめのテンポ・目標のテンポ・上げる幅・何小節ごとを設定
- リズムを作る：「パン(2)」「トマト(3)」のカードを並べてオリジナルの変拍子を作り、保存できる（次回も残る）
- ポリリズム（F）：3対2・4対3・5対4・5対3・5対2 を2つの音色と2つの図形で表示
- 大きな数字（投影用）・声の音色（パ・ン・ト・マ）

## 📘 レッスン（上の「📘 レッスン」ボタン）
- 9ステップ：同じ長さの拍 → パンとトマト（くらべる：3/4 と 6/8）→ 5/8 → 2+3と3+2 → 7/8 → 6/8と3/4 → 自分で作る → 当てる → まとめ（5枚のカード）
- 確かめは2〜3択。押すと正解と解説が出る。「🙋 挙手タイム」で問題と選択肢を画面いっぱいに出せる（答えはかくしておける）
- まとめ：①拍子記号の意味 ②強さの3段階 ③長さのちがう拍 ④まとまり方で拍子が変わる ⑤くり返し。「🔍 大きく」で1枚ずつ大きく出せる（PageDown で次のカード）
- 各ステップに「めあて・見るモード・やってみよう・確かめの質問（答えを見る）」。見るモードは自動で切りかわる
- 先生は「次へ」を押すだけ。PageDown／PageUp キー（プレゼン用リモコン）でも進める。全画面でも使える
- わかることタグ：モード一覧に「長さ・重心・周期・強さ」のタグ。タグを押すと、それがわかるモードだけ目立つ
- からだ：「授業で使う」で ON にすると、絵の下に 👣 足＝拍の頭、👏 手＝刻み が音に合わせて光る
- スマホでは、レッスンは小さくたためるカード（めあて1行＋前へ・再生・次へ）。「▼ くわしく」で全部見られる
- ステップを移ると、そのステップで使う画面だけが開く（ほかの設定の引き出しは閉じる）

## 画面の見かた（補足）
- テンポ：下の数字が4の拍子（2/4・3/4・4/4）と連符は「♩ = 80」と「♪ = 160」の両方、下の数字が8の拍子は「♪ = 160」
- くらべるモードでは、下のカード帯のかわりに楽譜が上の段・下の段の2段で出る（刻みの縦の位置がそろう）
- 「表示と音」→「下のカード帯を細くする」（はじめからON）：楽譜バーがONのとき帯を細くして絵を大きくする。全画面ではさらに細くなる

## メモ
- 画像・音声ファイルは使わず、音も絵もすべてプログラムで作っています。
- 見た目もすべてファイルの中に書いてあるので、インターネットにつながっていなくても動きます（設定と作ったリズムはブラウザに保存されます）。

## 楽譜バー
- 2小節ぶん並べて出す（交互パターンは2小節で1組）。拍子記号をタップすると意味の説明
- 拍の段（はじめからON）：刻みの段の下に、拍を1つの音符で出す（パン＝♩、トマト＝♩.）。右に「＝ 2拍子」。拍の頭で光る
- 4分の拍子の中の3つの刻みには「3」（3連符）の印
