# KineticRhythm（キネティック・リズム）

変拍子（5/8・7/8 など）の「いびつな重心・タメ・周期性」を、動きと音で体感するための教育用Webアプリです。

## 使い方
`index.html` をブラウザ（Chrome / Safari など）で開くだけで動きます。

- ▶ 再生ボタン（またはスペースキー）で開始・停止
- 上のタブで表示を切り替え：A 転がる多角形 / B 跳ねるボール / C 円軌道
- テンポ（8分音符 80〜300）、サブ拍クリック ON/OFF、音量、リズム・プリセットを変更できます

## プリセット
- 5/8 [2+3]（パン＋トマト） / 5/8 [3+2]（トマト＋パン）
- 7/8 [2+2+3] / 7/8 [3+2+2]
- 6/8 [3+3]
- 8/8 [3+3+2]（トレスティーヨ）

## メモ
- 画像・音声ファイルは使わず、音も絵もすべてプログラムで作っています。
- 見た目の部品（Tailwind CSS）をネットから読み込むため、インターネット接続が必要です。
